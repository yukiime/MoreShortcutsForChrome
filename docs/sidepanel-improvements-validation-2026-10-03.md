# 侧栏改进实现与验收记录

日期：2026-10-03，Asia/Tokyo。实现分支：codex/sidepanel-improvements。Chrome 沿用此前确认的本机 154.0.8037.93 arm64；不扩展为其他平台或版本结论。

## 已实现

- 复用同一工具栏按钮，一击在明确窗口创建真实 NTP，注册并打开新 tabId 的侧栏。命令使用相同回调结构，同步注册监听器，不经过初始化 Promise 或第二层 API callback。
- 侧栏内编辑名称和网址，HTTPS 规范化、版本冲突保护、后台单队列持久化；保存失败保留草稿，保存期间锁定输入，恢复侧栏重新同步。
- 默认关闭的持久常访问开关，临时收起/展开/刷新、可选历史授权、最多 20 个主机的访问次数榜单。
- 有界历史扫描、饱和时间窗拆分、URL 去重；无法完整扫描明确失败。权限、开关、菜单、历史删除与目标变化使旧排名/导航 token 失效。
- 独立 debugger/offscreen 实验构建，自动开关默认关闭；只附着自有 offscreen 文档，超时和失败清理，手动关闭取消在途自动打开。文档承载真实排名 Worker。

## 自动化验证与独立审查

最终 `npm test`：51 项通过、0 失败；`npm run check` 通过。两个 ZIP 的 testzip、manifest 权限和排除本地证据检查通过。

最终回归包含：持久化与失败原值、并发 revision、身份/路径/活动 NTP/pendingUrl/移窗校验、最新保存 URL 的导航、窗口与 token 隔离、在途历史失效、扫描预算/饱和时间戳/错误、草稿保护、权限回调、开关同步、旧响应不重开、恢复清单、保存锁定，以及实验清理与关闭取消。

独立只读审查发现恢复时清单不同步、保存期间输入丢失、手动关闭未取消在途自动打开三项 P2。另指出收起后缺少直接展开入口；按功能可达性升为 P2 并补按钮。四项均先补失败回归，再修复，整套检查重新通过。URL 带端口的无协议域名也补了失败回归后修复。

## 实施决定

| 决定 | 理由与影响 |
|---|---|
| 原目录新建本地功能分支，保留已有方案修改 | 用户要求自主实施且计划允许原目录；没有额外工作树，不推送发布 |
| 稳定版三项必需权限，实验版单独生成 | 不把调试权限加入日常版本；原生“+”实验还需要用户接受权限后运行验证 |
| 提取 panel-service 内部模块 | 用真实存储/控制器测试后台行为；增加一个内部模块，消息接口不变 |
| 设置增加默认关闭的 autoOpenEnabled | 供实验版使用，稳定版仅多一个布尔存储字段 |
| 补直接展开常访问按钮 | 避免收起后只能切换持久设置；顶部增加一个必要操作 |
| 保留功能分支与两个构建 | 等用户醒来审阅，不进行未经请求的 GitHub 发布或破坏原会话的浏览器重启 |
