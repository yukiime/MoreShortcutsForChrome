在置顶窗口中放下你的常用入口。保留这个控制页，悬浮窗口才能持续工作。

正在准备…

每次启动 Chrome 后，点击一次启动按钮并保留本页。之后用浏览器“+”或 Cmd+T 打开原生新标签页，工具尝试恢复同一个浮窗；离开或关闭新标签页时最小化保留。切到其他程序时，只要最近使用的 Chrome 窗口仍停在新标签页，就保持显示。Chrome 同时只保留一个画中画窗口，启动前请先关闭视频或其他画中画。关闭本页、刷新本页、关闭浮窗或重载扩展后，需要重新启动。

管理快捷方式与备份

在下方编辑或粘贴 JSON。保存前会检查格式，复制清单即可备份或迁移。不会修改原生快捷方式。

兼容性诊断

自动显示依赖 Chrome 当前的 PiP 窗口实现。若无法识别、隐藏或恢复窗口，页面会显示错误。API 状态不能单独证明屏幕可见性。
