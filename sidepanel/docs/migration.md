# 已有安装的数据与加载路径

新克隆本仓库时，直接在 Chrome 加载根目录 `extension/`。它是完整的独立扩展，不依赖其他仓库。

Chrome 已解压扩展的 ID 通常与加载路径相关。把原来的安装换到不同目录，可能得到不同扩展 ID；快捷方式、设置和命令绑定不会自动跨 ID 迁移。移除原安装会删除其本地数据。

如果此前安装来自 [总项目](https://github.com/yukiime/MoreShortcutsForChrome)，先保留该安装和原加载路径。总项目的原本机目录通过被 Git 忽略的兼容链接维护旧根目录路径，该链接不属于这个独立仓库。

本扩展尚无跨 ID 自动迁移工具，也没有一键导出全部本地数据。源码 ZIP 不包含个人编辑数据。需要保留现有数据时，继续在原扩展卡片“重新加载”，不要移除后另装。
