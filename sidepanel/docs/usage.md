# 使用细节与边界

## 编辑和持久化

默认包含 40 个示例条目。点击“编辑”后选择条目，在面板内修改名称和网址。网址仅允许无账号密码的 HTTP/HTTPS；无协议域名按 HTTPS 规范化。保存保留 ID、顺序和文字图标，取消或 Esc 不保存。

保存期间锁定输入，失败保留草稿。多个面板使用 revision 防止旧内容覆盖新修改。出现冲突时可“刷新版本并保留草稿”，再决定是否保存。恢复隐藏面板时重新同步清单。

已有 local 清单时，更新源码中的 `shortcuts.json` 不会覆盖它。数据损坏会报错，不静默重置。目前没有一键导入导出界面。

普通点击在面板所属窗口的活动 NTP 导航；⌘/Ctrl 点击或中键在同窗口新建后台标签，Shift 点击新建前台标签。目标失活、移窗、离开 NTP 或开始普通网页导航后，旧请求被拒绝。修饰键与中键的参数有自动测试，真实输入仍需更多浏览器复测。

## 常访问统计

“显示常访问”是持久开关，默认关闭。开启后打开或恢复侧栏会展开二级菜单。临时收起不改变设置，顶部“展开常访问”可以重新打开；关闭持久开关停止查询并清除列表和导航缓存。

首次读取需要点击“允许读取历史”，由 Chrome 请求可选 `history` 权限。拒绝后仍可使用自定义快捷方式。关闭开关不会撤销已授予权限，可在 Chrome 扩展权限设置中撤销。

排名按 History API 返回的 URL `visitCount` 汇总 hostname，合并 HTTP/HTTPS，不同子域分别计数；按次数、最后访问时间和主机名稳定排序。最多 20 项，不足不补齐。点击打开已观察到的主机根地址，优先 HTTPS。这是本扩展的统计口径，不是 Chrome 内部推荐榜单或去重的访问会话数。

扫描使用固定查询截止时间，每次最多 2048 个 URL。结果触上限时拆分时间窗，重叠边界并去重；最多 512 次查询、200000 个 URL。饱和时间戳或预算不足会明确报错，不把截断结果当完整排名。返回元数据仍是 Chrome 当前记录，不提供事务性历史快照。

历史结果只保存在内存。关闭开关、收起菜单、撤销权限或删除历史使旧请求与导航令牌失效。后台休眠后的旧令牌也会失效，刷新列表可恢复。

## 原生新标签自动显示

0.3.0 包含必需 `debugger` 和 `offscreen` 权限，自动开关默认关闭。在侧栏开启后，点击原生“+”即可尝试自动显示目标标签的侧栏。手动关闭后，刷新同一 NTP 不强制重开；创建新的 NTP 仍可自动显示。

实现只附着本扩展的隐藏文档，利用 CDP 临时用户激活和扩展消息调用逐标签 `sidePanel.open()`。隐藏文档还承载真实历史排名 Web Worker，以 `WORKERS` 理由创建。

Chrome 会显示调试提示，断开后提示仍可能短暂保留。成功、失败与超时路径均尝试断开；10 秒超时和附着后取消未单独模拟验收。错误诊断只存阶段和固定分类，不存原始调试错误文本。

自动链依赖浏览器调试能力，可能受版本、调试占用或用户取消影响。失败保留 NTP，使用工具栏按钮或已配置命令即可继续。当前运行验收限于 Chrome 154；自然休眠、浏览器重启和跨版本恢复尚未验收。

## 诊断

扩展选项页显示配置和最多 120 条短期 API 事件。注册成功不能证明界面已打开，调试释放的开始日志也不能证明断开完成。实际可见性应与浏览器观察结合判断。
